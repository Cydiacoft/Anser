# Anser - 大学生安全知识学习平台自动答题助手

自动答题与题库抓取工具，适配 `njtd.dxsaqxx.top` 在线学习平台。

## 功能

- **题库抓取**：在线学习模式下自动提取题目与答案，保存到本地题库
- **自动答题**：考试模式下从题库匹配答案并自动勾选
- **视频学习**：自动播放视频，处理防挂机弹窗
- **自动跳转**：支持自动进入下一题/下一个视频

## 环境要求

- Python 3.8+
- Tampermonkey 浏览器扩展

## 快速开始

### 1. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

### 2. 启动本地服务

```bash
python server.py
```

服务启动后访问 `http://127.0.0.1:5000`，题库保存在 `question_bank.json`。

### 3. 安装油猴脚本

1. 在浏览器中打开 Tampermonkey 管理面板
2. 点击"添加新脚本"
3. 将 `tampermonkey.js` 的内容复制粘贴进去并保存
4. 确保脚本已启用

### 4. 使用方法

访问 `njtd.dxsaqxx.top` 登录后，页面右上角会显示 Anser 控制面板：

| 按钮      | 功能                       |
| ------- | ------------------------ |
| 开启自动抓库  | 在线学习模式下自动提取题目和答案，保存到本地题库 |
| 当前题获取答案 | 手动查询当前题目的答案并勾选           |
| 开启自动考试  | 自动答题并跳转下一题（考试模式）         |

## 配置说明

油猴脚本中的可配置项位于脚本开头：

```javascript
const CONFIG = {
    serverUrl: "http://127.0.0.1:5000",
};
```

## 题库文件

- 路径：`question_bank.json`
- 格式：JSON，键为题目文本，值为答案文本

## 注意事项

- 仅供学习交流使用，请遵守平台服务条款
- 首次使用建议先手动刷一遍在线学习以积累题库
- 考试模式需确保题库中有足够题目覆盖
